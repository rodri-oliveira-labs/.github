# Rodri Oliveira Labs

**Software Architecture · .NET · Distributed Systems · Developer Tooling · Cloud · Governance as Code**

Rodri Oliveira Labs builds open-source libraries, developer tools, reference implementations, templates, and automation that turn software architecture decisions into practical, testable, and reusable engineering assets.

The focus is on keeping architecture close to implementation, making decisions explicit, and using automation to validate quality, reliability, security, and architectural constraints.

## What we build

Projects in this organization focus on:

- **Software Architecture**  
  Architecture as code, C4 modeling, ADRs, architectural fitness functions, and automated validation.

- **Distributed Systems**  
  Reliability patterns, messaging, idempotency, consistency, observability, and failure handling.

- **.NET Engineering**  
  Libraries, analyzers, tooling, templates, and reusable infrastructure for modern .NET applications.

- **Developer Experience**  
  CLI tools, repository automation, GitHub Actions, templates, and workflows that reduce repetitive engineering work.

- **Governance as Code**  
  Automated guardrails for quality, security, documentation, architecture, and software supply chain practices.

- **Cloud & Platform Engineering**  
  Reproducible infrastructure, deployment patterns, observability, and cloud-native reference implementations.

## Engineering principles

The projects maintained here generally follow a few principles:

- Start with the problem, not the pattern.
- Make architectural decisions and trade-offs explicit.
- Treat operational concerns as part of the design.
- Prefer automated guardrails over manual bureaucracy.
- Keep architecture close enough to the code to validate assumptions.
- Favor deterministic and reproducible tooling.
- Use secure defaults and least-privilege automation.
- Preserve compatibility when evolving established public contracts.
- Make documentation part of the engineering workflow.

## Projects

This organization is intended to host open-source projects that can be useful beyond a single application or team.

Depending on the project, repositories may include:
