# Rodri Oliveira Labs

**Arquitetura de Software · .NET · Sistemas Distribuídos · Developer Tooling · Cloud · Governança como Código**

A Rodri Oliveira Labs desenvolve bibliotecas open source, ferramentas para desenvolvedores, implementações de referência, templates e automações que transformam decisões de arquitetura de software em ativos de engenharia práticos, testáveis e reutilizáveis.

O foco é manter a arquitetura próxima da implementação, tornar decisões explícitas e usar automação para validar qualidade, confiabilidade, segurança e restrições arquiteturais.

## O que construímos

Os projetos desta organização têm foco em:

- **Arquitetura de Software**  
  Arquitetura como código, modelagem C4, ADRs, architectural fitness functions e validação automatizada.

- **Sistemas Distribuídos**  
  Padrões de confiabilidade, mensageria, idempotência, consistência, observabilidade e tratamento de falhas.

- **Engenharia .NET**  
  Bibliotecas, analyzers, ferramentas, templates e infraestrutura reutilizável para aplicações .NET modernas.

- **Developer Experience**  
  Ferramentas CLI, automação de repositórios, GitHub Actions, templates e workflows que reduzem trabalho repetitivo de engenharia.

- **Governança como Código**  
  Guardrails automatizados para qualidade, segurança, documentação, arquitetura e práticas de software supply chain.

- **Cloud & Platform Engineering**  
  Infraestrutura reproduzível, padrões de deployment, observabilidade e implementações de referência cloud-native.

## Princípios de engenharia

Os projetos mantidos aqui seguem, de forma geral, alguns princípios:

- Começar pelo problema, não pelo padrão.
- Tornar decisões arquiteturais e trade-offs explícitos.
- Tratar preocupações operacionais como parte do design.
- Preferir guardrails automatizados a burocracia manual.
- Manter a arquitetura próxima o suficiente do código para validar suas premissas.
- Favorecer ferramentas determinísticas e reproduzíveis.
- Usar defaults seguros e automações com menor privilégio.
- Preservar compatibilidade ao evoluir contratos públicos já estabelecidos.
- Tratar documentação como parte do fluxo de engenharia.

## Projetos

Esta organização tem como objetivo hospedar projetos open source que possam ser úteis além de uma única aplicação ou equipe.

Dependendo do projeto, os repositórios podem incluir:

- bibliotecas reutilizáveis;
- ferramentas para desenvolvedores;
- ferramentas de arquitetura;
- implementações de referência;
- templates e golden paths;
- GitHub Actions;
- analyzers;
- projetos experimentais e provas de conceito.

À medida que os projetos forem sendo consolidados nesta organização, esta seção passará a destacar os principais repositórios e seus respectivos objetivos.

Cada repositório define sua própria política de suporte, diretrizes de contribuição, garantias de compatibilidade e ciclo de releases.
